## 概要

株式会社artkakeの[公式コーポレートサイト](https://www.artkake.co.jp/)の設計・開発を全て担当。

## 多言語対応

i18n（国際化）を導入し、複数言語に対応。言語切り替えにより、日本語・英語などでコンテンツを閲覧できる構成に。

- ルーティングベースの言語切り替え
- 各言語ごとの SEO メタタグ最適化
- コンテンツの翻訳管理

## 技術スタック

### CMS
- **microCMS** — コンテンツ管理

### アナリティクス
- **Google Analytics GA4** — アクセス解析

### JavaScript フレームワーク
- **React** — UI ライブラリ
- **React Router 7** — ルーティング
- **GSAP** — アニメーション

### セキュリティ
- **HSTS** — HTTP Strict Transport Security

### フォント
- **Google Font API** — Web フォント配信

### タグマネージャー
- **Google Tag Manager** — タグ管理

### PaaS
- **Vercel** — ホスティング・デプロイ

### その他
- **Open Graph** — OGP 対応
