## 概要

サウナ施設の検索・予約ができるプラットフォーム「[Saufull](https://saufull.com/)」の設計・開発を全て担当。フロントエンドからバックエンド、インフラまで一貫して構築。

## 技術スタック

### CMS / CDN
- **microCMS** — コンテンツ管理
- **Cloudflare** — CDN・エッジ配信

### アナリティクス
- **Cloudflare Browser Insights** — パフォーマンス計測
- **Google Analytics** — アクセス解析

### 支払い処理
- **Stripe** — 決済基盤

### タグマネージャー
- **Google Tag Manager** — タグ管理

### JavaScript フレームワーク
- **Next.js** — React フレームワーク
- **React** — UI ライブラリ

### UI フレームワーク
- **Panda CSS** — CSS-in-JS

### その他
- **Open Graph** — OGP 対応
- **HTTP/3** — 高速通信プロトコル
